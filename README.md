# Onue Line Cruises

Versioned multi-page website for the fictional Onue Line fleet.

Current release: `v2.1.0-alpha.3` — Booking Experience.

Includes responsive core pages, nine shared ship profiles, original fleet artwork, a fleet gallery, touch-friendly mobile navigation, structured fleet data, and cabin pricing of $50 Interior, $250 Oceanview, and $500 Suite per guest.

Run `npm install` and `npm run dev`, then open the local address shown.
