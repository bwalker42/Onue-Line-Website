# Onue Line Cruises

Versioned multi-page website for the fictional Onue Line fleet.

Current release: `v2.1.0-beta.1` — Deck Plans & Destinations.

Includes responsive core pages, ten shared ship profiles, original fleet artwork, a fleet gallery, touch-friendly mobile navigation, structured fleet data, and cabin pricing of $50 Interior, $250 Oceanview, and $500 Suite per guest.

Run `npm install` and `npm run dev`, then open the local address shown.
