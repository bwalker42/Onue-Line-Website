# Onue Line Cruises

Versioned multi-page website for the fictional Onue Line fleet.

Current release: `v2.1.0-alpha.1` — Foundation.

Includes responsive core pages, nine ship profiles, shared styling, structured fleet data, and cabin pricing of $50 Interior, $250 Oceanview, and $500 Suite per guest.

Run `npm install` and `npm run dev`, then open the local address shown.
