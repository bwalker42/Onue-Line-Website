# v2.1.0-alpha.2 — Fleet Experience

Alpha.2 moves Onue Line from a styled foundation to a visual fleet experience. Original ship photography is now stored inside the project and used by the homepage, fleet directory, gallery, and shared ship profile route.

Mobile navigation now opens as a large touch-friendly menu. Fleet images use responsive crops so the ships remain visible on iPhone as well as desktop.

The booking flow and detailed interactive deck plans remain scheduled for alpha.3 and beta.1.
